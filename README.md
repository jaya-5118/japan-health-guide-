MediConnect Japan is a unified healthcare and elderly tourism ecosystem built for Japan's aging society (29.1% of population aged 65+) and doctor shortages in rural prefectures (e.g., Aomori).

The platform links **Patients, Caregivers, Doctors, Regional Municipal Health Admins, and International Senior Tourists** into an AI-coordinated care network featuring voice-first assistance, 3D glassmorphism UI, real-time medical translation, and instant 119 emergency dispatch protocols.

---

## 🌟 Key Features

- **👴 Patient Care Portal (Takeshi Sato)**: Large-touch medication adherence tracking, voice commands, blood pressure monitoring, and 119 emergency SOS.
- **👩‍⚕️ Caregiver Command Center (Yuki Sato)**: Real-time patient monitoring, alerts, and autonomous shift handoff with backup activation.
- **🩺 Doctor EHR & Telehealth (Dr. Tanaka)**: Comprehensive health records, specialist referrals to Tokyo University Hospital, and live telehealth consultation with prescription titration.
- **📊 Regional Health Analytics (Kenichi Mori)**: Demographic aging heatmaps, clinic capacity tracking, and HIPAA/PMDA compliance audit exports.
- **🗼 Senior Tourist Guide (Arthur Miller)**: 
  - Barrier-free accessible destinations directory with audio guides and Japanese taxi destination cards.
  - Multilingual voice & speech assistant (English, Chinese, Korean, Spanish, French) with one-touch Japanese pronunciation.
  - Emergency SOS and digital Japanese Medical Triage Card for paramedics.
  - Accessible transit navigator (Universal Design Taxis & JR station staff escort services).
- **🤖 6 Autonomous AI Agents**: Adherence escalation, emergency symptom NLP triage, specialist referrals, telehealth translation, caregiver handoffs, and vital spike detection.
- **📄 Complete Project Documentation PDF**: Includes `MediConnect_Japan_Documentation.pdf` detailing dataset origins, frontend/backend architecture, and usage manual.

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/jaya-5118/japan-health-guide-.git
cd japan-health-guide-

# 2. Install dependencies
npm install

# 3. Launch local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.
